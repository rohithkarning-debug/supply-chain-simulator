### 5. Non-Functional Requirements

The non-functional requirements define the quality attributes, operational constraints, and performance baselines of the Supply Chain Management Simulator. All measurements are established against the Python 3.11 runtime environment.

| Req ID | Requirement | Category | Priority | Acceptance Criteria / Measurement |
|---|---|---|---|---|
| SCM-NF-001 | The system shall execute a 365-day run of the baseline demo scenario in $\le 1.0$ s, and the 10-day command-line demo (including Python interpreter startup and shutdown) in $\le 1.0$ s on a standard laptop with Python 3.11. | Performance | Medium | AC-SCM-NF-001: Execution time of `build_demo().run(365)` $\le 1.0$ s (measured baseline ~0.02 s) and CLI invocation `python -m scm_sim --days 10 --seed 42` $\le 1.0$ s (measured baseline ~0.10 s) across 3 consecutive runs. Test: TC-PERF-01 |
| SCM-NF-002 | The system shall produce identical daily reports and final summary output on every run and host platform when supplied with the identical random seed and simulation scenario configuration. | Reliability / Reproducibility | High | AC-SCM-NF-002: Two separate simulation runs with `--seed 42` generate 100% byte-for-byte identical daily logs and analytics reports; runs with different seeds (e.g., `--seed 7`) exhibit deterministic variations matching the pseudorandom sequence. Test: TC-REP-01 |
| SCM-NF-003 | The system test suite shall maintain $\ge 90\%$ line code coverage across the entire `scm_sim` package, measured automatically by `pytest-cov` on every GitHub Actions CI run; all tests must pass before merging any pull request. | Maintainability | High | AC-SCM-NF-003: Automated execution of `pytest -v --cov=scm_sim` reports $\ge 90\%$ statement coverage (measured baseline 97%) and zero failing tests on GitHub Actions ubuntu-latest. Test: TC-COV-01 |
| SCM-NF-004 | The system shall run across Windows, Linux, and macOS platforms on Python $\ge 3.11$ using solely the Python standard library (`dataclasses`, `enum`, `random`, `argparse`) at runtime, requiring third-party dependencies (`pytest`, `pytest-cov`) strictly for development and testing. | Portability | Medium | AC-SCM-NF-004: Clean environment verification: simulator runs and produces reports on Windows 11 and Ubuntu without any `pip install` runtime packages; `requirements.txt` contains only test dependencies. Test: TC-COV-01 |
| SCM-NF-005 | The system shall provide an intuitive command-line interface enabling a new user to execute the simulation scenario using a single documented command (`python -m scm_sim`), provide self-documenting option summaries via `--help`, and present clean report formatting displaying explicit item counts and printing "No issues" for empty report categories. | Usability | Medium | AC-SCM-NF-005: Executing `python -m scm_sim --help` outputs comprehensive CLI usage and parameter options; running the default demo prints formatted sections with counts and "No issues" for sections with zero anomalies; invalid inputs like `--days 0` terminate with exit code 2. Test: TC-SIM-02 |
