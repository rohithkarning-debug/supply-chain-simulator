### 5.1 Security Requirements

#### 5.1.1 Security Objectives
The Supply Chain Management Simulator implements defense-in-depth principles appropriate for an in-memory discrete-event simulation engine and its development pipeline:

1. **SCM-SO-1 (Integrity of Simulation Data):** The system shall guarantee that all inventory, customer order, supplier, and shipment states remain strictly valid throughout the simulation lifecycle. The system state shall never transition into corrupted or physically impossible states (such as negative stock, exceeded warehouse capacity, illegitimate status regressions, or unvetted entity generation), even when supplied with invalid, malicious, or out-of-order input sequences.
2. **SCM-SO-2 (Integrity and Traceability of the Codebase):** The project shall ensure that only peer-reviewed, automatically verified, and auditable code is integrated into the production branch (`main`). Every modification must trace to a specific team member, a feature branch, and an approved Pull Request, preventing unauthorized code injection or regressions.
