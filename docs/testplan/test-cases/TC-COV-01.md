| **TC ID** | TC-COV-01 |
| **Title** | Test Coverage Gate and Cross-Platform Portability |
| **Requirement(s)** | SCM-NF-003, SCM-NF-004 |
| **Type** | Maintainability |
| **Objective** | Verify that the automated suite maintains at least 90% line coverage of the `scm_sim` package and that all tests pass before a merge is permitted, and that the simulator runs unchanged on Windows, Linux and macOS on Python 3.11 or later using only the standard library at runtime. |
| **Preconditions** | *Automated part:* the repository is hosted on GitHub and the GitHub Actions `test` job is enabled for the `main` branch and for pull requests. *Manual part:* a Windows 11 machine with Python 3.11 and a Linux machine with Python 3.11, each with `pytest` and `pytest-cov` installed from `requirements.txt`. |
| **Test data** | The whole test suite: `tests/test_inventory.py`, `tests/test_orders.py`, `tests/test_shipments.py`, `tests/test_simulator.py` and `tests/test_analytics.py`. The demo scenario `build_demo(seed=42)` used for the manual runs: suppliers `SUP-RELIABLE` and `SUP-FLAKY`, warehouses `WH-NORTH` and `WH-SOUTH`, SKUs `WIDGET`, `GADGET`, `GIZMO`, customer `C-ACME`. `requirements.txt` is inspected for runtime dependencies. |
| **Steps** | *Automated part.* 1. Push a commit to a feature branch and open a pull request to `main`, or push directly to `main`.<br>2. Wait for the `test` job on `ubuntu-latest` with Python 3.11 to complete.<br>3. Read the job log for the pytest summary and the coverage report for `scm_sim`.<br>4. Confirm that a pull request cannot be merged while this check is failing.<br>*Manual part.* 5. On Windows 11, create a clean virtual environment, install `requirements.txt`, and run `pytest -v --cov=scm_sim`.<br>6. On Windows 11, run the demo: `python -m scm_sim --days 10 --seed 42`.<br>7. Repeat steps 5 and 6 on a Linux machine.<br>8. Inspect `requirements.txt` and confirm it contains only `pytest` and `pytest-cov`.<br>9. Confirm that no third-party package is required to run the simulator, by running it in an environment where only the standard library is available.<br>10. Record the OS, OS version and Python version used in each manual run. |
| **Expected result** | 1. A `test` check is reported for the commit on both branches.<br>2. The job completes successfully.<br>3. The log reports all 73 tests passing with 0 failures, 0 errors and 0 skipped, and a total line coverage of `scm_sim` of at least 90% (measured baseline 97%).<br>4. The "merge" control is unavailable while the check is failing, so an untested change cannot reach `main`.<br>5. The suite runs to completion on Windows 11 with the same pass count and no platform-specific error.<br>6. The demo prints the day-by-day log and the final report and exits with code 0.<br>7. The same results are obtained on the Linux machine.<br>8. `requirements.txt` lists only the two test dependencies and no runtime package.<br>9. The simulator starts and runs with no runtime package installed.<br>10. The environment details are recorded in the test report. |
| **Pass/fail criteria** | **Pass** if the CI `test` job reports 0 failing tests and coverage of `scm_sim` of at least 90% on every push to `main` and every pull request, the check is enforced as a merge condition, and the suite and demo both run successfully on Windows and on Linux with only the standard library available at runtime. **Fail** if any test fails or is skipped without a recorded reason, if coverage falls below 90%, if a pull request can be merged while the `test` check is red, if the suite or demo errors on either manual host, or if any runtime third-party dependency is found to be necessary. |
| **Automated by** | GitHub Actions `test` job in `.github/workflows/ci.yml`, running `pytest -v --cov=scm_sim` on `ubuntu-latest` with Python 3.11 on every push to `main` and every pull request: 73 passed, 97% coverage (CI run #20, commit `b3702ef`). |
| **Actual result** | Automated part: Pass — 73 passed, 97% coverage (CI run #20, commit `b3702ef`). Manual part (clean-environment run of the suite and the demo on Windows 11 and on a Linux machine): Not run. |
