### 10. Risks and Mitigation

The following risk matrix identifies potential quality, execution, and integration risks identified during test planning, along with proactive mitigation strategies and contingency actions:

| Risk ID | Risk Description | Severity | Likelihood | Mitigation Strategy | Contingency Plan |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **RSK-01** | **Nondeterministic Test Failures (Flaky Tests):** Stochastic delay generation causes intermittent test failures when using unseeded random numbers. | High | High | Enforce dependency injection of seeded pseudorandom number generators (`random.Random(42)`) in `ShipmentManager` and `Simulation`. In unit tests, either pass explicit `delay` parameters or explicit seed integers. | If a test fails unpredictably, inspect whether global `random` was invoked instead of the injected `self.rng` instance. |
| **RSK-02** | **Continuous Integration Service Outage:** GitHub Actions service downtime prevents automated check execution and blocks PR merges. | Medium | Low | Maintain full local test parity. All team members configure `.venv` locally with identical dependencies (`pytest`, `pytest-cov`) and must achieve 100% pass rates locally before opening PRs. | Team lead temporarily verifies test execution via signed local run logs if emergency integration is mandated. |
| **RSK-03** | **Module Interface Incompatibility:** Parallel development by four engineers leads to signature mismatches during integration into `simulator.py`. | High | Medium | Freeze and publish exact public API signatures, parameters, exceptions, and return types in `SCM_PROJECT_CONTEXT.md` §4.5 prior to module construction. | Dedicated integration test suite (`tests/test_simulator.py`) exercises end-to-end multi-module flows on every PR. |
| **RSK-04** | **Cross-Platform Inconsistencies:** Discrepancies between Windows local developer environments and Linux CI runners (e.g., line endings, CLI shell parsing). | Medium | Low | Rely exclusively on cross-platform Python standard library modules (`argparse`, `sys`). Run full automated regression on `ubuntu-latest` CI for every Windows push. | Author cross-platform tests (`TC-COV-01`) verifying CLI invocation syntax across both Windows PowerShell and Linux bash. |
| **RSK-05** | **Test State Pollution:** Tests modifying shared global state, causing cascading order-dependent test failures. | High | Low | Pure object-oriented encapsulation: every test instantiates fresh, isolated object instances (`Inventory()`, `OrderManager(inv)`). Zero module-level mutable variables. | Pytest executes tests with randomized order during test auditing to verify complete independence. |
